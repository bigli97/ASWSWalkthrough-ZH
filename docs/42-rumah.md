# 鲁玛村

> 本章为中文初译，待人工审核。原文版本：0.6.2.0。

<!-- source:0001 -->
跟随[蒂娅](09-tia.md)的任务线来到这里。

<!-- source:0002 -->
1. 希芭：可通过给她精液酒使她堕落（背包中同时有葡萄酒和一瓶精液时使用葡萄酒，参见[卢修斯](14-lucius.md)任务）。
    
    - 这样做 5 次后（每次都必须间隔一天），她会想离开丈夫。蒂娅必须达到 C11+，否则你必须把她留在母亲那里或小屋中。你必须在决斗中击败她丈夫（还会掉落可给蒂娅装备的皮甲）。
    - 在与希芭的后续场景中，蒂娅会根据自身 C 对你与希芭在一起作出反应。这也会反映在你与蒂娅于小屋中的性场景里。
    - 若 3 天不与希芭发生性行为，她会在早上你睡在小屋时来拜访你。

<!-- source:0003 -->
2. 阿伊塔：将帕拉克要求的肉交给他后，再次与他交谈。他会告诉你自己爱上了阿伊塔，希望她注意到自己。更多信息参见[阿伊塔](46-ayita.md)。

<!-- source:0004 -->
3. 乌敏：给他带来木材后再次与他交谈；他会用 5 根长生木换给你一把新弓。
